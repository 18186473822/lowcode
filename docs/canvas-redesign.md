# 画布页重设计（2026-10-29）

> 范围：`apps/designer-web/src/App.vue` 的画布视图、`packages/designer/src/canvas/LcCanvas.vue`、
> 左右两栏（`MaterialPanel` / `PropsPanel`）。门户清单与工作区五视图不在本批范围内。

## 1. 简报

- **对象**：移动门户的设计工作面。使用者是实施顾问 / 运营，不是终端员工。
- **主要任务**：看 375 宽的真实页面、选中节点、在右栏改配置；次要任务是换设备档位与缩放。
- **约束**：沿用既有 `--lc-*` 令牌与「单张白色工作台 + 1px 分隔线 + 22/18/14/13/12 字号」语言；
  不新增品牌色；所有数字必须来自实际 schema / store。

## 2. 方向：校样台，不是仪表盘

画布页应该像一张**校样台**：中间只有一件东西（手机页面），周围的尺规、档位、读数都退到边缘。
它不该像 SaaS 首页那样用一排卡片解释自己，也不该用蓝色提示条教用户操作。

三个特征：

1. **一条仪表轨**：面包屑与工具条各 44px，连续白底 + 1px 分隔；设备档位用内凹轨道上的白色滑块，
   不是一排蓝色 chip。
2. **一只带框的样机**：手机页面外有一圈 8px 中性边框（`bg-subtle` + 1px 描边 + 20px 圆角），
   让 375 宽的内容成为唯一“实物”；不加假状态栏、不加刘海。
3. **一条读数栏**：画布底部 32px 固定读数，显示页面类型、卡片/组件数量、宽度与缩放。
   这是本页的“签名元素”，也是把提示条信息转成事实的地方。

## 3. 令牌

| 角色 | 取值 | 用途 |
|---|---|---|
| 工作面 | `--lc-bg-canvas` | 画布区底色，比白更低一档 |
| 仪表面 | `--lc-bg-surface` | 面包屑 / 工具条 / 读数栏 / 左右栏 |
| 次级面 | `--lc-bg-subtle` | 档位轨道、设备框、行悬停 |
| 墨色 | `--lc-text-primary` / `--lc-text-secondary` | 页名 / 说明与读数 |
| 发丝线 | `--lc-border-default` | 所有分隔 |
| 唯一强调 | `--lc-action-primary` | 选中、焦点、当前设备滑块的上边线（≤ 3 处） |

不新增色值；不使用渐变、彩色蒙层或大圆角卡片堆叠。

## 4. 字体与字号

- 家族：`--lc-font-ui`（Noto Sans SC）；id、缩放、尺寸读数用 `--lc-font-mono`。
- 级差：页名 13/600；面包屑与工具条 12；读数 11；分组标题 12。
- 数字只出现在读数栏与缩放值里，不为了“数据感”添加装饰性数字。

## 6. 左栏

- 搜索框置顶（高 32，`bg-subtle` 底，放大镜 14px），输入即筛；有输入时分组自动展开。
- 分组头 = 折叠箭头 + 名称 + 计数，高 30，`text-secondary`；点击折叠。
- 物料行 = 16px 线性图标 + 名称 + 右侧 `+`（悬停/键盘焦点可见），高 32；悬停 `bg-subtle`。
- 行本身可点击直接追加到页面，也保留 HTML5 拖拽；两种入口文案一致。
- 取消原 2 列虚线卡片——41 个物料用它太吵，且虚线在暗色下像禁用态。

## 7. 右栏

- 选中节点时，**节点区在最上**：标题 + id + 四个操作（上移 / 下移 / 复制 / 删除），
  然后是绑定字段、事件、settings、权限点。
- 页面设置收进底部可折叠区，摘要一行（`门户 · 4 张卡片`），默认在选中节点时折叠；
  未选中节点时默认展开，保证首次进入能改页面类型。
- 门户卡片改为“折叠行 + 展开编辑”：行头显示图标字、标题、目标页/链接、角标；
  行内操作提供上移 / 下移 / 复制 / 删除；展开后编辑标题、说明、图标、页面、链接、角标。
- 不把长卡片列表放在节点属性上方。

## 8. 自检

- 是否模板化？把相同的线框换成任意后台都会成立的部分只有“搜索 + 列表”，
  但读数栏、设备轨道、样机边框是画布工具特有的；没有使用奶油底 + 衬线、黑底荧光、
  报纸栏或统一圆角卡片。
- 是否有装饰？没有渐变、没有阴影堆叠（只有样机一层 `shadow-e2`）、没有为数字而数字。
- 暗色：全部取令牌；设备框 `bg-subtle` 与页面 `bg-surface` 在暗色下仍有 1px 描边区分。
- 900px：左右栏转抽屉（浮层），中栏 900 宽；375 样机完整可见，无横向滚动；
  页头事实 <1100 隐藏，底栏缩放 <900 隐藏，二者仍有等价读数或出口。
- 可访问性：折叠按钮 `aria-expanded`，搜索 `aria-label`，行 `role=button` + Enter/Space，
  设备档位 `aria-pressed`，焦点环沿用 `--lc-focus-ring`。
