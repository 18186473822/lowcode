## 1. Phase 1：Web 设计器（5 批）

**目标**：业务人员在 Web 端拖拽建页 → 配置属性/字段/动作 → 保存发布 → 移动端按 Schema 渲染。

**架构决策**

| 编号 | 决策 |
|---|---|
| D-A1 | 设计器与运行时**同源渲染**：PC 上复用 uni 组件（uni-shim + 增强器），避免两套组件漂移 |
| D-A2 | `designMode` 是 renderer 唯一的设计态扩展点；选中/遮罩/动作拦截都在宿主层 |
| D-A3 | Schema 操作全部进 `packages/designer` 的 `core/` 纯函数，不污染 renderer |
| D-A4 | 物料来源 = materials 包的静态 META 注册表，设计器不连服务端物料接口 |
| D-A5 | 拖拽用原生 HTML5 DnD，不引第三方拖拽库 |
| D-A6 | 保存/发布走注入的 `DesignerApi` 接口，设计器核心不直接发请求 |
| D-A7 | 状态分层：画布/选中/剪贴板在 store，服务端副作用在宿主 |
| D-A8 / D-A9 | 批 2/3 的收口决策与偏差注记 |
| D-A11 | 页面↔模型**双层配置**：页面级「提交模型」+ 节点级「绑定字段」 |
| D-A12 | 必填联动：校验规则引用字段时，属性面板联动 display |
| D-A13 | 最小动作绑定：事件 → 无参动作；有参动作留后续 |

**批次与出口**

| 批次 | 目标 | 结果 |
|---|---|---|
| 1 | 画布能渲染 | ✅ 3 容器 + 12 物料真渲染、rpx→px、选中/遮罩 |
| 2 | 能拖入删除 | ✅ 插入/换位/删除、大纲树、快捷键、13 份 META 合流 |
| 3 | 能配置保存 | ✅ 4 类 setter 真控件、校验、保存/打开/发布链路 |
| 4 | 页面↔模型字段绑定 | ✅ 双层配置、提交新增记录、字段绑定提示 |
| 5 | 出口判据闭环 | ✅ 必填联动 + 动作绑定 + 闭环 Demo；出口判据 1/2/3 全通 |

**Phase 1 出口判据**：拖拽建页 → 绑定模型 → 提交记录 → 服务端可查 → 列表可见（列表页由 Phase 2 补齐后兑现）。

## 2. Phase 2：企业级能力（7 批）

**目标**：从「能建页」到「能交付业务应用」——模型建模、标准页、物料扩容、可用性、版本、权限、多端。

| 批次 | 目标 | 关键决策 | 结果 |
|---|---|---|---|
| 1 | 模型可视化建模 | D-P2-1 视图切换，模型编辑不离开设计器 | ✅ |
| 2 | 列表/详情标准页 | D-P2-2 协议补 `DetailPageConfig`；配置驱动，画布仅占位 | ✅ |
| 3 | 物料 12→30 | D-P2-4 对齐 `FieldType` 全集，补 optionList/color setter | ✅ 实际 33 个组件目录 |
| 4 | 设计器可用性 | D-P2-7 快照双栈撤销重做 + 大纲树 + 跨页剪贴板 | ✅ |
| 5 | 版本管理 UI | D-P2-8 补版本列表接口；D-P2-9 自研结构化 diff | ✅ 历史/回滚/对比 |
| 6 | RBAC 权限 | D-P2-10 单文件配置；D-P2-11 四层判定单一事实源；D-P2-12 权限视图 | ✅ 页面/按钮/数据行级 |
| 7 | 出口 Demo + 多端 | B-41 默认值清理；D-P2-13 受控回显兜底 | ✅ 请假三页 Demo + 小程序分包产物 |

**Phase 2 出口判据**：30 分钟内搭出「申请→列表→详情」；小程序端产物级跑通（真机受环境限制）。

## 3. Phase 3：流程与体验（5 批）

**目标**：带审批的业务闭环 + 移动端体验（草稿、主题、门户、图表、埋点）。

| 批次 | 目标 | 关键决策 | 结果 |
|---|---|---|---|
| 1 | 流程引擎核心 | D-P3-1 `FlowSchema`/`validateFlow`；D-P3-2 assignee 判定；D-P3-3 依赖方向 | ✅ 7 接口 + 提交联动 + 待办/审批 |
| 2 | 审批物料 + 待办中心 | D-P3-4 物料数据通道；D-P3-4b `$expr` recordId；D-P3-5 待办两页；D-P3-6 单实例接口 | ✅ 同意/驳回/时间轴 |
| 3 | 本地草稿 + 主题 | D-P3-7 草稿时机/存储分层；D-P3-8 `apps.json` 主题；D-P3-9 dark 优先级 | ✅ 用户隔离 + 7 天过期 + 品牌十档 |
| 4 | 图表 + Portal 页型 | D-P3-10 纯 SVG 三形态；D-P3-11 `PortalPageConfig` 卡片导航 | ✅ 另修 B-45~B-48（RPC 超时、缓存、rpx） |
| 5 | 埋点 + Profiler | D-P3-12 ops 三接口；D-P3-13 上报队列；D-P3-14 双端性能角标 | ✅ 不白屏 + `?perf=1` |

**Phase 3 出口判据**：申请提交 → 待办 → 同意 → 记录状态变更 + 时间轴可见；门户图表 + 主题换色。

**明确裁剪**：消息通知、数据导出/打印（留 Phase 4，至今未开发）；离线队列、BPMN（方案二期）。
